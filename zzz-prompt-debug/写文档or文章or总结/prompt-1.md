16. 总结对话/知识/文档（优化版）

    ```md
    你回顾一下刚才我们的对话，整理一下，整理成一个文档给我，包括但不限于：

    1. **前因后果**：这个事情为什么这么做，为什么不那么做，当时的决策逻辑和约束条件是什么。

    2. **例子说明**：用具体的例子说明某个概念或决策的意义，让抽象的东西变得可感知。

    3. **知识延伸（举一反三）**：从当前讨论的主题出发，往相关领域做自然的知识延伸和对比。关键原则：
       - 延伸方向由**当前主题本身**决定，不要套用固定模板
       - 对比的维度可以是：不同语言/框架对同一问题的设计差异、不同场景下的取舍权衡、底层原理的横向关联等
       - 延伸的目的是让读者建立**知识网络**，而不是做百科全书式的罗列
       - 每个延伸点要说清楚：**为什么这么设计、不同方案各自的 trade-off 是什么**
       - 举例（仅供参考，不要照搬）：讨论 JS 垃圾回收时，可以延伸到 C/C++/Java/Python/Rust 的内存管理，对比各自的设计哲学和适用场景——但这是"讨论内存管理"时的自然延伸方向；如果你在讨论数据库索引，延伸方向可能是 B+树 vs LSM树、不同数据库的索引实现差异，而不是内存管理

    4. 把文档写到 `zzz-docs` 目录下，文件名能体现主题内容。
    ```
