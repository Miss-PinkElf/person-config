## 关键决策与原因

- 采用 VS Code Extension API 实现，不改 VS Code 源码：扩展 API 已覆盖首版目标。
- 首版选择完整 22 项能力：用户明确选择 B。
- 实施拆成 3 个里程碑：完整范围较大，分阶段更便于验证和回退。
- 频率排序只统计受控树内打开行为：避免全局打开统计的口径复杂度。
- 默认排序展示和配置索引分离：避免 inline 移除删错 JSON 条目。
