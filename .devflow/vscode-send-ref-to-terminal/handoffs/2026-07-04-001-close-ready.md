# Handoff：vscode-send-ref-to-terminal 收尾交接

## 当前目标

开发 VS Code 插件（VS Code Extension）`vscode-send-ref-to-terminal`，把当前编辑器选中的代码行引用发送到当前活动终端（Active Terminal），且不自动执行。

## 关键决策与原因

- 采用极简独立扩展（Minimal Standalone Extension）：核心痛点明确，先保证稳定可用。
- 核心逻辑不按系统分支：VS Code Extension API 跨平台。
- 默认快捷键按平台声明：macOS 用 `Cmd+Shift+L`，Windows/Linux 用 `Ctrl+Shift+L`。
- 引用路径统一 `/`：避免 Windows 反斜杠影响 Claude Code 引用格式。
- 第一版不做终端识别、终端重命名、多选区和配置项：这些会扩大不稳定面，已记录到延期项。
