# 快捷键打开指定文件：需求对齐（Align）

## 目标

开发独立的 VS Code 插件（VS Code Extension）。用户可在 `keybindings.json` 中添加任意多条快捷键（Keybinding）；每条快捷键打开不同的指定文件，并按该条配置把光标放到文件末尾或最后一个非空字符之后。

原始需求标题写“定位文件夹”，用户已明确本轮只需要打开文件，不需要定位文件夹。

## 配置与使用

插件注册一个打开文件命令（Command），由快捷键规则通过 `args` 传入参数。每条规则至少配置 `path`，可以另配 `cursor` 和 `workspaceFolder`。插件不预设占用任何快捷键。

```jsonc
[
  {
    "key": "cmd+alt+1",
    "command": "quickOpenTarget.openFile",
    "args": { "path": "notes/today.md", "cursor": "end" }
  },
  {
    "key": "cmd+alt+2",
    "command": "quickOpenTarget.openFile",
    "args": { "path": "/Users/example/notes/inbox.md", "cursor": "lastContent" }
  }
]
```

以上按键只是文档示例；用户自行选择不冲突的快捷键。Windows 与 Linux 的示例将使用对应系统可用的路径及修饰键。

## 路径规则

- 绝对路径（Absolute Path）直接定位本机文件，不依赖当前工作区。
- 工作区相对路径（Workspace Relative Path）在单根工作区（Single-root Workspace）相对于该根目录解析。
- 多根工作区（Multi-root Workspace）使用相对路径时必须配置 `workspaceFolder`，值为唯一的工作区文件夹名称；缺失或名称重复时显示错误，不猜测当前目标。
- `workspaceFolder` 只用于相对路径；与绝对路径同时提供时提示参数错误，避免配置被静默忽略。
- 没有打开工作区时，相对路径显示错误。相对路径不得通过 `..` 越出所选工作区根目录；工作区外文件可使用绝对路径。
- 第一版面向本机文件（Local File）；不扩展 `~`、环境变量或 VS Code 变量，不支持 URI 字符串。

## 光标规则

- `cursor: "end"` 为默认值。光标放在真正的文件末尾（End of File），包括结尾换行和空行之后，适合直接追加内容。
- `cursor: "lastContent"` 把光标放在最后一个非空白字符之后；结尾的空格、制表符和换行均跳过。空文件或全空白文件落在文档起点。
- 打开文件后将编辑器切到前台，设置单一光标位置，并滚动到该位置。打开和定位均不修改文件内容。

## 组件与处理流程

1. 快捷键规则调用 `quickOpenTarget.openFile` 并传入参数。
2. 参数与路径解析单元校验 `path`、`cursor`、`workspaceFolder`，确定文件 URI。
3. 命令处理单元确认目标存在且是文件，调用 VS Code 编辑器 API 打开文档。
4. 光标位置单元按模式计算位置，更新编辑器选区（Selection）并显露该位置。
5. 参数无效、路径不明确、文件不存在或无法打开时，显示可理解的错误消息，不创建目标文件。

## 方案比较

| 方案 | 优点 | 代价 | 结论 |
| --- | --- | --- | --- |
| 每条快捷键直接传路径与光标模式 | 数量不限、配置集中、结构最小 | 用户需编辑 `keybindings.json` | 采用 |
| 快捷键传目标名称，路径另放设置 | 多快捷键可复用同一目标 | 需要维护两处配置 | 暂不采用 |
| 预设固定数量的命令槽位 | 在快捷键界面容易查找 | 槽位数量固定，扩展复杂 | 暂不采用 |

## 验收与文档

- 同一安装实例中至少配置两条快捷键，分别打开不同文件，并验证两种光标模式。
- 覆盖相对路径、绝对路径、多根工作区参数校验、空文件、末尾换行、全空白文件以及无效目标。
- 编写中文使用说明（README），说明安装、配置样例、模式语义和错误处理。
- 插件可以编译、测试并打包为 VSIX；在 VS Code 中的手动快捷键验证若当前环境无法执行，应明确记录待验证步骤。

## 范围边界

本轮不做文件夹定位、图形化快捷键管理、自动创建不存在的文件、远程 URI 打开或默认快捷键。现有插件保持独立，不与受控文件浏览器（Controlled Explorer）耦合。
