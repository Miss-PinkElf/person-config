# 第一版路径限制

## 暂不做的对象

第一版不展开 `~`、环境变量和 VS Code 变量，不接受 URI，也不解析远程工作区里的相对路径。

## 本轮不做的原因

对齐时把第一版限定为本机文件。展开变量和远程路径会改变“路径文本对应哪个文件”，本轮没有讨论具体规则。

## 当前已有思路

遇到这些写法时直接显示中文错误，不猜测目标。绝对路径仍然可以打开本机文件。

## 后续触发条件

用户明确要求支持用户主目录、`${workspaceFolder}`、环境变量，或要在远程窗口里使用相对路径。

## 推荐进入阶段

先做 Mini Align，确认每一种写法的解析基准，再改 `openTarget.ts` 和测试。
